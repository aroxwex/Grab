# Changelog

All notable changes to Grab are listed here.

## 1.0.0

First public release.

- One box for links, YouTube search and local files (paste, type, open or drop)
- In-app player with visual trimming, several kept parts that get joined, volume 0-200% and screenshots
- Video (MP4 / MKV / WebM, every offered resolution with an estimated size) and audio (MP3 / M4A / Opus / WAV)
- Full screen player
- Cookies support (browser or cookies.txt) with automatic fallback when cookies can't be read
- Disk space checks before the player copy and before downloads, and a single temporary player file that is cleaned up automatically
- Portable build: one folder with `Grab.exe` and `bin`
